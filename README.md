## 2. Ý nghĩa các câu lệnh Git đã sử dụng trong bài

| Câu lệnh | Ý nghĩa |
| :--- | :--- |
| `git init` | Khởi tạo một kho lưu trữ Git cục bộ (Local Repository) ngay tại thư mục bài làm trên máy tính. |
| `git remote add origin <URL>` | Tạo liên kết giữa kho cục bộ với kho chứa từ xa (Remote Repository) trên GitHub dưới định danh `origin`. |
| `git add README.md` (hoặc `git add .`) | Đưa các tệp vào khu vực chuẩn bị (Staging Area) để Git theo dõi trước khi lưu. |
| `git commit -m "Add README.md file"` | Lưu lại ảnh chụp trạng thái của tệp vào lịch sử Git cục bộ kèm thông điệp mô tả thay đổi. |
| `git branch -M main` | Đặt lại tên nhánh chính thành `main` để đồng bộ chuẩn với GitHub. |
| `git push -u origin main` | Đẩy các commit từ máy tính cá nhân lên nhánh chính trên GitHub và thiết lập theo dõi giữa hai nhánh. |
